## 2. 기존 제품 개선 아이디어

### A-라인 개선안
**탈착 커버 시스템 도입 (우선순위: 최상)**
- 현재 스웨이드 원단 봉제 구조 → 지퍼 탈착형 이중 커버 구조로 변경
- 외부 커버: 기존 극세사 스웨이드 유지 / 내부 인너 커버: 흡습속건 항균 원단(냉감 옵션 추가 가능)
- 기대효과: 세탁 불편 해소, 계절별 커버 교체판매로 객단가 상승(커버 단품 1만5천 원 선 판매)
- 디자인 무결성: 지퍼를 후면 하단에 숨겨 심플한 외관 유지

### Cozy-라인 개선안
**논슬립 베이스 패널 추가 (우선순위: 상)**
- 현재 구조: 하단 스웨이드 처리만 있음
- 개선: 하단 전면에 실리콘 논슬립 도트 패턴 접착 처리 (돌침대·흙침대 표면 마찰 최적화)
- 추가로 상단 양쪽에 벨크로 앵커 테이프 탑재 → 벽면 부착 없이 자석 또는 흡착식 고정 옵션 제공
- 기대효과: '밀림' 불만 완전 해소, 돌침대 전용 완성도 강화

## 3. 파생·변형 제품 아이디어

### 높이 조절형 모듈 웨지 쿠션 — "따숨마루 핏(FIT)-라인"
- **개념**: A-라인 삼각 웨지를 베이스(1단)로, 상단에 추가 웨지 모듈(+3cm / +6cm)을 탈착 결합하는 모듈형 구조
- **타겟**: 기존 A-라인 구매 고객 중 "높이가 아쉽다"는 피드백층 + 체형 고려 맞춤 구매 희망 고객
- **차별점**: 한 제품으로 3가지 경사각(표준 / +3cm / +6cm) 대응 → 허리·흉추 지지 구간 개인화
- **가격 전략**: 베이스 단품 2만5천 원 + 모듈 세트 1만 원 → 번들 3만5천 원 구성
- **주의점**: 모듈 연결부 이탈 방지 구조(마그네틱 or 후크) 설계 필수, 사용 중 이격 시 안전 리스크 있음

## 5. 소싱 추천 제품

### 기능성 허리쿠션 전용 탈착 커버 원단 소싱
- **품목**: 흡습속건 항균 극세사 스웨이드 (냉감 기능 추가 버전)
- **소싱 채널**: 국내 섬유단지(대구 섬유단지, 화성 원단 클러스터) 또는 알리바바 B2B (MOQ 500m 기준 협상)
- **타겟 스펙**: 
  - 소재: 폴리에스터 95% + 스판덱스 5% (기존 스웨이드 질감 유지)
  - 기능: 항균 처리(은 이온 코팅) + 냉감(접촉 냉감 지수 Q-max 0.18 이상)
  - 색상: 기존 차콜 그레이 / 웜 베이지 동일 컬러 매칭 필수
- **예상 원단 단가**: 1,800~2,500원/m (국내 기준)
- **추천 이유**: 탈착 커버 시스템 도입 시 즉시 활용 가능, 냉감 버전은 여름 시즌 신규 커버 상품으로 판매 가능

## 6. 시너지 제품 아이디어 (돌침대 사용자 주변 용품)

### 아이디어 1: 따숨마루 온열 발받침대 (Footrest)
- **개념**: 돌침대 위에서 앉을 때 종아리·발뒤꿈치가 딱딱한 표면에 닿는 불편함 해소
- **구성**: 소형 직사각 쿠션 (약 40×25cm), 하단 논슬립, 상단 스웨이드 소재 — 등받이 쿠션과 세트 구성
- **기대 효과**: 등받이 쿠션 + 발받침대 세트 판매 시 객단가 1.8배 상승, "돌침대 편안한 좌식 세트" 번들 기획 가능
- **색상**: 차콜 그레이 / 웜 베이지 동일 컬러 → 세트 비주얼 완성도

### 아이디어 2: 돌침대 전용 측면 포켓 오거나이저
- **개념**: 돌침대 옆면에 걸거나 끼워 쓰는 슬림 포켓형 수납 — 리모컨, 책, 핸드폰, 물병 등 수납
- **타겟 니즈**: 돌침대는 소파와 달리 사이드 테이블 없이 사용하는 경우 많음 → 손닿는 곳에 소지품 보관 니즈
- **소재**: 동일 스웨이드 계열 or 두꺼운 캔버스 + 실리콘 그립 패드
- **연결 전략**: 등받이 쿠션 구매 고객에게 "함께 쓰면 더 편한 세트" 크로스셀링

## 7. 이번 주 기획·개발 우선순위

### 우선순위 1 — 탈착 커버 시스템 기획안 확정 (D-day: 이번 주 금요일)
- A-라인 지퍼 탈착형 커버 구조 설계 → 샘플 제작사 컨택
- 커버 단품 소싱 원단 후보 2~3종 샘플 수령 목표
- 커버 색상 확장(여름: 쿨 화이트 / 겨울: 딥 네이비 등) 라인업 기획

### 우선순위 2 — Cozy-라인 논슬립 베이스 개선 샘플 발주
- 실리콘 논슬립 도트 패턴 부착 샘플 제작 요청 (기존 재고 리뉴얼 적용 여부 검토)
- 테스트: 돌침대 표면 3종(대리석, 황토, 맥반석)에서 밀림 테스트 진행

### 우선순위 3 — "건강지능 루틴" 콘텐츠 방향성 기획 브리핑
- 트렌드 키워드(건강지능, 에이징 인 플레이스)를 접목한 제품 스토리라인 정리
- 상품 상세페이지 리뉴얼 키워드: "매일 돌침대에서 바르게 앉는 습관" → 허리 건강지능 실천
- 마케팅팀·블로그팀과 콘텐츠 방향 공유 필요
